# PocketCore AI product page

Single-page site for **PocketCore AI — Modular Pocket Smart Gadget** (₹1,299).

Live site (GitHub Pages): https://pioneerfurnitures1820-prog.github.io/pocketcore-ai-page/

## Update the page

1. Edit `index.html` in this repository.
2. Commit and push to the `main` branch.
3. GitHub Pages will republish in a minute or two.

Do not add a custom Jekyll layout; `.nojekyll` keeps the HTML as-is.
